对当前项目生成 i18n 覆盖率报告。

## 执行步骤

1. 确定项目路径：使用用户提供的路径参数，如果没有提供则使用当前工作目录
2. 调用 MCP tool `i18n_generate_report`，传入 `path` 参数
3. 展示报告结果，重点突出：
   - 总体覆盖率百分比
   - 覆盖率最低的文件（优先处理）
   - 各语言的 key 完整性
4. 提供改善建议：
   - 如果覆盖率低于 80%：建议优先处理覆盖率最低的文件
   - 如果某语言 key 缺失较多：建议批量补充翻译
   - 如果覆盖率已达 95%+：恭喜接近完成

## 注意事项

- 覆盖率 = 已使用 t() 的字符串 / 总中文字符串
- 报告不包含不可转换的中文（这些不应计入覆盖率）

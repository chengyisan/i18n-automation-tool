---
description: 初始化 i18n 配置文件（.i18nrc.json）
---

为当前项目生成 i18n 配置文件。

## 执行步骤

1. 确定项目路径：使用用户提供的路径参数，如果没有提供则使用当前工作目录
2. 检查项目是否已有 .i18nrc.json：
   - 如果已存在：询问用户是否要覆盖
   - 如果不存在：继续生成
3. 询问用户配置选项（如果用户没有指定）：
   - 支持的语言列表（默认 zh-CN, en-US）
   - 默认语言（默认 zh-CN）
   - 语言包目录（默认 src/lang）
4. 调用 MCP tool `i18n_init_config`，传入用户选择的参数
5. 展示生成的配置内容，询问用户确认
6. 确认后将配置写入 .i18nrc.json

## 注意事项

- 配置文件使用 JSON 格式
- 语言代码推荐使用 BCP 47 格式（zh-CN, en-US, ja-JP 等）
- langDir 路径相对于项目根目录

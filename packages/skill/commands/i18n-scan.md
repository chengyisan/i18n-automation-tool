---
description: 扫描项目中的硬编码中文字符串、不可转换中文和重复翻译
---

对当前项目执行 i18n 硬编码扫描。

## 执行步骤

1. 确定扫描路径：使用用户提供的路径参数，如果没有提供则使用当前工作目录
2. 调用 MCP tool `i18n_scan_hardcoded`，传入 `path` 参数
3. 展示扫描结果给用户
4. 根据结果提供下一步建议：
   - 如果发现硬编码中文：建议使用 `/i18n-fix` 进行交互式修复
   - 如果发现不可转换中文：说明这些需要手动处理（后端值、图片文字等）
   - 如果发现重复翻译：建议合并到公共翻译文件
   - 如果未发现问题：恭喜，建议运行 `/i18n-check` 做更深入的检查

## 注意事项

- 扫描结果按文件分组展示
- 如果项目没有 .i18nrc.json 配置，提示用户先运行 `/i18n-init`
- 对于大型项目，可以指定子目录缩小扫描范围

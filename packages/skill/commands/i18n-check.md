对当前项目执行全面的 i18n 质量检查。

## 执行步骤

1. 确定项目路径：使用用户提供的路径参数，如果没有提供则使用当前工作目录
2. 依次调用以下 MCP tool：
   - `i18n_check_reactive`：检查 Vue 文件中的 t() 响应式问题
   - `i18n_check_quality`：检查翻译质量（中式英语、冗余表达等）
   - `i18n_check_layout`：检查 CSS 固定宽度/高度等布局适配问题
3. 汇总所有检查结果，按严重级别排序展示
4. 提供修复建议：
   - 响应式问题：给出 computed/watch 的修复代码示例
   - 翻译质量：给出改写建议
   - 布局问题：建议使用 min-width/max-width 替代固定宽度

## 注意事项

- 如果某项检查无问题，简短提示即可，不需要展开
- 响应式检查只针对 .vue 文件
- 翻译质量检查针对语言包中的非基准语言
- 布局检查针对 CSS/SCSS/Vue 文件中的样式

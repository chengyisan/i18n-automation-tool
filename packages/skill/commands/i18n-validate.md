对当前项目执行 i18n 配置验证。

## 执行步骤

1. 确定项目路径：使用用户提供的路径参数，如果没有提供则使用当前工作目录
2. 调用 MCP tool `i18n_validate_setup`，传入 `path` 参数
3. 展示验证结果给用户
4. 根据结果提供下一步建议：
   - 如果配置有问题：逐条说明修复方案
   - 如果 key 缺失：列出缺失的 key，建议补充翻译
   - 如果有多余 key：建议清理不再使用的翻译
   - 如果验证通过：恭喜，建议运行 `/i18n-report` 查看覆盖率

## 注意事项

- 如果项目没有 .i18nrc.json，提示用户先运行 `/i18n-init`
- key 完整性检查基于配置中指定的 baseLocale 作为基准
